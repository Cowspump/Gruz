# Грузпроект

Одностраничный сайт грузоперевозок на React, TypeScript, Vite и GSAP. Раздел
грузов оформлен интерактивной 3D-каруселью DepthCarousel.

## Локальный запуск

В терминале из папки проекта выполните:

```bash
npm install
npm run dev
```

После запуска откройте в браузере адрес, который покажет Vite (обычно
`http://localhost:5173/`).

## Проверка и production-сборка

```bash
npm run lint
npm run build
npm run preview
```

`npm run preview` запускает локальный просмотр уже собранной production-версии.

## Важно перед публикацией

- Контактный номер и WhatsApp сейчас заданы в `src/App.tsx` константами
  `PHONE_DISPLAY` и `PHONE_E164`.
- Форма не отправляет данные на сервер: она открывает WhatsApp с подготовленным
  текстом заявки.
- Фотографии загружаются с Unsplash, а шрифты — с Google Fonts, поэтому для их
  отображения нужен интернет.
- Перед публикацией нужно проверить номер, тексты, реальные показатели компании и
  подключить домен/хостинг.
